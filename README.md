# AOD — Always On Display & Keep Screen Awake 📱

Современное Android-приложение для постоянного поддержания экрана смартфона во включенном состоянии в эстетике **Slate Dark Material Design 3 (MD3)**.

---

## ✨ Ключевые возможности

1. **Режим «Экран всегда включен» (Keep Screen Awake)**:
   - Переключение в одно касание через фирменную органическую волнистую кнопку (Scallop Button).
   - Поддержание активности через `FLAG_KEEP_SCREEN_ON` и фоновую службу `ForegroundService` с `WakeLock`.
2. **Плитка быстрых настроек (Quick Settings Tile)**:
   - Включение/отключение удержания экрана прямо из системной шторки Android без необходимости открывать приложение.
3. **Заставка Always On Display (AMOLED Pitch Black)**:
   - Полноэкранный режим с глубоким черным фоном (`#000000`), который отключает подсветку OLED-пикселей и экономит до 78% заряда батареи.
   - Минималистичные цифровые часы, дата, процент заряда и статус зарядки.
   - **Защита от выгорания OLED-матрицы**: динамическое смещение координат элементов каждые 60 секунд.
   - Выход из заставки двойным тапом по экрану.
4. **Умные триггеры и таймеры**:
   - Автоматическая активация только при подключении зарядного устройства.
   - Таймеры отключения: 15 минут, 30 минут, 1 час или бесконечный режим.
5. **Дизайн в стиле ryNet / MD3**:
   - Slate Dark палитра (`#0D1117` / `#151A21`).
   - Округлые карточки (20–28dp) и пилюльные элементы навигации.
   - Плавные анимации состояний.

## 🚀 Сборка проекта

Для сборки требуется **Android SDK** и **Java 17** (например, из комплекта Android Studio):

```powershell
# Установка JDK 17
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:Path = "$env:JAVA_HOME\bin;" + $env:Path

# Сборка Debug APK
cd android-apps\aod
.\gradlew.bat assembleDebug
```

Готовый файл APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
